# Zatlas feedback

[Zatlas](https://zatlas.app) is a free, non-commercial DayZ map built from the game's own World data: loot, a 3D View, routes and Groups for your squad. Five Worlds so far: Nasdara, Chernarus, Livonia, Sakhal and Namalsk. More DayZ tools will follow.

This repo is where you tell us what's broken, what's missing and which map to add next.

## How to report

1. Search the [open issues](https://github.com/myhrmans/zatlas-feedback/issues) first. If someone already said it, add a 👍 or a comment.
2. Otherwise [open a new issue](https://github.com/myhrmans/zatlas-feedback/issues/new/choose) and pick one:
   - **Bug**: something is wrong or doesn't work.
   - **Idea**: a feature or a change you'd like.
   - **Map request**: a community map you want on Zatlas (the Steam Workshop id helps).
3. For bugs, the page address (it includes the World and the spot) and a screenshot save a lot of guessing.

Keep it friendly, and don't post anything private, such as passwords, invite links to your Group or server addresses you don't want public.
